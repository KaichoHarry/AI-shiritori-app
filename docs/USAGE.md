# しりとりWebアプリ 使用書(ユーザーマニュアル)

- 作成日: 2026-07-21(改訂)
- 対象: 本アプリのエンドユーザー
- 対応する設計書: DESIGN.md (v0.4)

## 1. アプリの概要

ブラウザで遊べるしりとりアプリ。以下の3つのモードを搭載する。

1. ソロプレイ: 自分ひとりでしりとりを続けるモード
2. AI対戦: AIと交互に単語を出し合うモード
3. フリートーク(文章しりとり): AIと日常会話を紡ぎながら、文章単位でしりとりのように言葉をつなげていくモード

ログイン後、ダッシュボードから各モード・設定・過去のログにアクセスできる。

## 2. 動作環境

- 通常のWebブラウザ(PC・スマートフォン)からアクセス可能
- 利用にはアカウント登録・ログインが必要

## 3. アカウント登録・ログイン

1. ログイン画面でメールアドレスとパスワードを入力してログインする
2. アカウントを持っていない場合は、ログイン画面の「アカウントをお持ちでない方はこちら」から新規登録画面に移動し、メールアドレスとパスワードを登録する
3. パスワードを忘れた場合は、ログイン画面の「パスワードをお忘れの方はこちら」からパスワード再設定を申請する。登録済みのメールアドレスを入力すると申請が管理者に通知される
4. 管理者が申請内容を確認して承認すると、登録済みのメールアドレス宛に新しいパスワードが届く。届いたパスワードでログインし、必要であれば改めてパスワードを変更する
5. ログインに成功するとダッシュボード画面に移動する
6. ログアウトはメニューからいつでも行える

## 4. ダッシュボード

ログイン後の最初の画面。以下への入り口がまとまっている。

- 「ソロプレイ」「AI対戦」「フリートーク」の3モード
- 「設定」: モード2のデフォルト難易度、モード3の会話トーンを変更できる
- 「履歴」: 過去にプレイしたゲーム・会話の記録一覧

## 5. 設定

- モード2(AI対戦)のデフォルトの難易度(易しい/普通/難しい など)を設定できる。ゲーム開始時に個別に変更することも可能。
- モード3(フリートーク)でAIと話すときの雰囲気・テンション(例: フレンドリー、丁寧、コント風 など)を設定できる。

## 6. モードの遊び方

### 6.1 ソロプレイモード

1. ダッシュボードから「ソロプレイ」を選ぶ
2. 最初の単語を入力する
3. 画面には直前に入力した単語(のお尻の文字)だけが表示される。それより前の単語は画面上には表示されないが、記録には残っている
4. 次の単語は、直前の単語の最後の文字から始まる言葉を入力する。入力欄の上には、次に入力すべき音がひらがな・カタカナ両方で案内表示される
5. 入力した言葉が辞書に存在しない場合は「この言葉は辞書に見つかりませんでした」というメッセージが表示され、ゲームオーバーにはならず、そのまま別の言葉を入力し直せる
6. 以下のいずれかに当てはまると、その時点で「ゲームオーバー」画面が表示される
   - 入力した単語が「ん」で終わった
   - すでに一度使った単語をもう一度入力した
7. ゲームオーバー後は、使った単語の一覧や回数を結果画面で確認できる

### 6.2 AI対戦モード

1. ダッシュボードから「AI対戦」を選ぶ(難易度は設定画面のデフォルト値が使われるが、開始時に変更もできる)
2. 自分の単語を入力すると、AIが続きの単語を自動で返してくる。ソロプレイと同様に、次に入力すべき音のヒントが入力欄の上に表示される
3. 自分が入力した言葉が辞書に存在しない場合は、ソロプレイと同様にエラーメッセージが表示され、ゲームオーバーにはならず入力し直せる
4. 交互に単語を出し合い、しりとりを続ける
5. 以下の場合、ゲームが終了する
   - 自分が「ん」で終わる単語を出した、または既に使った単語を出した → 負け
   - AIが「ん」で終わる単語しか出せなかった、既に使った単語を出した、辞書に存在しない言葉を出した、または単語を思いつけなかった(応答できなかった) → 勝ち
6. 難易度を上げると、AIがより間違えにくく、難しい単語を出しやすくなる

### 6.3 フリートークモード(文章しりとり)

1. ダッシュボードから「フリートーク」を選ぶ
2. 単語ではなく、**文章**でAIと日常会話のようなやり取りをする。自分の発言の最後の音から、AIが次の発言を始める(その逆もある)、文章版のしりとりのようなノリで会話が続く
3. 会話のトーンは設定画面で選んだもの(フレンドリー/丁寧/コント風 など)が反映される
4. 文末が「。」「!」のような句読点・記号・絵文字で終わっていても構わない。それらは無視され、その手前にある最後のひらがな・カタカナ・英字まで遡って次の音が決まる(漢字も同様に読み飛ばされる)。AIが返事を考えている間は「AIが返事を考えています」という表示が出るので、応答が届くまでそのままお待ちいただきたい
5. 発言が「ん」の音で終わると、その時点で会話(チェーン)が終了する
6. それ以外でも、自分で「終了する」ボタンを押せばいつでも会話を終えられる
7. 終了すると、それまでの会話ログが記録として保存される

## 7. 過去のログを見る

1. ダッシュボードの「履歴」を開く
2. 日時・モード・結果(勝ち/負け/ゲームオーバー/会話終了など)の一覧が表示される
3. 一覧から選ぶと、そのときの単語履歴や会話内容を詳しく見返せる

## 8. よくある質問

**Q. 入力した言葉が辞書にない場合、負けになりますか?**
A. なりません。ソロプレイ・AI対戦モードでは、辞書に存在しない言葉を入力してもゲームオーバーにはならず、エラーメッセージが表示されて別の言葉を入力し直せます。

**Q. 途中でやめたい場合は?**
A. フリートークモードは「終了する」ボタンでいつでも終了できる。ソロプレイ・AI対戦モードはゲームオーバー(または勝敗)になるまで続く仕様(途中終了機能は今後の検討事項)。

**Q. 同じ単語をもう一度使うとどうなる?**
A. ソロプレイ・AI対戦モードでは、そのセッション内で一度使った単語を再度入力するとゲームオーバー(または敗北)になる。

**Q. 「ん」で終わる単語・発言を入力するとどうなる?**
A. ソロプレイ・AI対戦モードではその時点でゲームオーバー(AI対戦モードではAIがそうなった場合は自分の勝ち)になる。フリートークモードでは、その時点で会話(チェーン)が終了する。

**Q. 「カフェ」「ティー」のような外来語の言葉の次は、何から始まる言葉を入力すればいい?**
A. 「ファ・ティ・ディ・チェ・シェ・ジェ」のような小さい母音(ぁぃぅぇぉ)を使う音は、拗音(ゃゅょ)と同じく直前の文字とあわせて1つの音として扱われる。たとえば「カフェ」の次は「ふぇ」または「フェ」から始まる言葉を入力する(入力欄の上のヒント表示にも従うとよい)。
